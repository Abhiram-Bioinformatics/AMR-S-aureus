# Web-based analyses

Several analyses in this project were performed through web interfaces rather than as local WSL command-line workflows. These steps are documented here instead of being represented by artificial shell scripts.

## IslandViewer

### Purpose
Prediction and examination of genomic islands in the three assembled SRA genomes.

### Input
Genome assemblies:

- ERR12712640
- ERR12712641
- ERR13347068

### Output
Predicted genomic-island annotations were downloaded and used during genomic-context interpretation and construction of the Integrated AMR Evidence Table.

According to the final project report, IslandViewer predicted nine genomic islands in ERR12712640, nine in ERR12712641, and six in ERR13347068. No AMR or virulence genes were identified within the predicted genomic islands.

## SCCmecFinder

### Purpose
SCCmec typing and characterization of the genomic context of `mecA`.

### Input
The three assembled SRA genomes.

### Output
SCCmec typing results were downloaded for downstream interpretation.

The final report records:

- ERR12712640 — SCCmec type II (2A)
- ERR12712641 — SCCmec type IVc (2B)
- ERR13347068 — SCCmec type IVa (2B)

## InterProScan

### Purpose
Functional annotation of representative proteins from seven priority AMR genes.

### Local preparation
Representative protein sequences were selected from CARD-RGI output using:

`scripts/08_protein_annotation/02_prepare_interproscan_input.py`

The resulting FASTA file was submitted to the InterProScan web interface.

### Output
The downloaded TSV annotations were reviewed and used to prepare the InterPro Summary Table.

## STRING

### Purpose
Investigation of functional associations among the seven priority AMR proteins.

### Input
The selected priority AMR genes/proteins.

### Output
The resulting interaction network was incorporated into the biological interpretation.

The final project report identified an interaction between GyrA and ParC with a combined STRING score of 0.753. The remaining mapped proteins did not show direct interactions under the selected confidence setting.

## Manual/downstream integration

The following project outputs were assembled from results generated by multiple analyses rather than from a single local script:

- InterPro Summary Table
- Integrated AMR Evidence Table
- STRING interpretation

The Integrated AMR Evidence Table combines RGI, Panaroo, RNA-seq differential expression, InterProScan, SCCmecFinder, IslandViewer, and MobileElementFinder evidence.
